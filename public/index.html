Why Final-Year Engineering Students Procrastinate on AI

The 3 Real Friction Points

  • Overwhelming Theory: 40-hour online courses lead to tutorial fatigue with 0 deployed output.
  • Environment Barrier: CUDA, GPU, Python venv, and dependencies cause immediate drop-off.
  • Placement Urgency: Final years need tangible proof-of-work on their resume immediately.

The AI60 Value Proposition

  • Hands-on Output: Build, connect, and demo one working project in 60 minutes.
  • Zero Install: Web-based cloud editor aims to remove environment setup headaches.
  • Project Submission: Submit your repo and demo link after the workshop (automated evaluation planned).
